Réglages

Pour écrire depuis cette page (ajouter un concert, mettre un disque en wantlist), il faut un jeton GitHub. Il reste dans ce navigateur et n'est jamais envoyé ailleurs qu'à GitHub.

Comment créer le jeton. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Choisis uniquement ce dépôt, permission Contents : Read and write, et une expiration courte. Ce jeton ne peut rien faire d'autre que modifier ce dépôt : c'est le point important.
Les écritures créent un commit, qui déclenche le workflow. Compte une à deux minutes avant que la modification revienne dans les données affichées.

Données recalculées à chaque passage du workflow. Une écoute = un titre joué au moins 30 secondes. Genres et notoriété ne sont pas fournis par l'API : ils viennent d'une classification manuelle.
